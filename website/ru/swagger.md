# Swagger и OpenAPI

Справочник описывает настоящий `POST https://i.instagram.com/graphql_www`:
один endpoint и девять именованных примеров запросов.

[Открыть Swagger UI](swagger-ui/index.html){ .md-button .md-button--primary }
[Скачать OpenAPI](openapi.json){ .md-button }

Выберите операцию, чтобы увидеть её persisted ID, параметры и закодированную форму.
`variables` — JSON-строка внутри `application/x-www-form-urlencoded`.

Отправка запросов и ввод сессии в интерфейсе отключены. Выполняйте запросы через
SDK на своём backend. Все файлы Swagger находятся на сайте, внешнего CDN нет.

Схема raw-ответа открытая: один пример не выдаётся за полную серверную схему.
[Состав данных](data-reference.md) и [границы проверки](verification.md) описаны отдельно.
