# Что проверено и откуда взяты данные

## Уровни доказательств

| Уровень | Значение |
|---|---|
| `live-verified` | SDK или исходный клиент получил ответ сервера; смотрите semantic_status и область проверки |
| `static-contract` | Назначение, переменные и/или разбор ответа восстановлены по APK |
| `static-reference` | Найдена запись в реестре и ссылка из Java-кода; полного контракта нет |
| `registry-only` | Найдены имя и persisted ID; достижимость и параметры не доказаны |

Эти статусы описывают исследование, а не обещание будущей работы API.

## Реальный запрос

18 октября 2026, 12:29 UTC исходный клиент выполнил
`BaselReelDetailsQuery` к `https://i.instagram.com/graphql_www` с
`client_doc_id=3261342854360971614358769315`, `include_creative_tools=false`.
Получены HTTP 200, JSON с Content-Type `text/javascript; charset=utf-8`,
62 числовые точки, последовательные индексы 0..61. Владелец из составного media ID
совпал с ID сессии. Авторизация была получена по явному разрешению владельца,
использована в памяти и не опубликована.

[Обезличенное свидетельство](evidence/live-verification.json) содержит digest
ответа, размер и свойства схемы. Исходный ответ намеренно не включён: он содержит
персональную аналитику и URL медиа. Digest — ссылка на зафиксированный локальный
артефакт, не возможность независимо восстановить или проверить его содержимое.

## Проверка SDK 0.2.0

18 октября 2026 выполнены девять операций чтения из установленного в исходниках
SDK и один дополнительный запрос следующей страницы Reels. Все десять вернули
HTTP 200. [Обезличенные результаты](evidence/method-verification.json) содержат
время, digest, размер и описание фактически полученного результата.

| Операция | Проверенный результат |
|---|---|
| BaselReelDetailsQuery | Метрики и 62 точки удержания |
| BaselPublicInsightsQuery | Счётчики и коэффициенты собственного Reel |
| BaselAccountLevelInsightsQuery | Агрегаты и временные ряды за LAST_30_DAYS |
| BaselAccountLevelReelsQuery | Две страницы по 3 узла, cursor принят, без пересечения ID |
| BaselAudienceInsightsQuery | Демография, география, рост и активность подписчиков |
| XIGBaselAccountLevelReelsDataDeltaQuery | Метрики для одного переданного ID |
| XIGBaselInsightsCommentsQuery | Запрос принят, ai_comment_insights=null |
| BaselKitsQuery | Запрос принят, edges=[], следующей страницы нет |
| ReelInsightsQuery | Альтернативная кривая и демография, сборка NDJSON |

HTTP 200 здесь не приравнивается к полноте функции. Заполненные комментарии и Kits
не проверены. Использован один аккаунт с его разрешения и один Reel; многозначные
batch-запросы, все enum-комбинации, другие аккаунты и срок жизни сессий не проверены.
Ни одна mutation не запускалась. Статус live-verified означает только наблюдение,
зафиксированное рядом с методом. Остальные записи каталога не повышены в статусе.

Сессия использована только в памяти. Персональные ответы хранятся отдельно от
публичного проекта. Digest нельзя использовать для восстановления или независимой
проверки содержимого отсутствующего ответа.

Отсутствующее/null/пустое/all-null удержание проверено синтетически, а не получено
на реальном выбранном Reel: у него кривая была доступна. Упакованная версия SDK
проверяется отдельно установкой wheel и теми же офлайн-тестами; это не новый живой запрос.

При исходном исследовании проверены подпись APK и DEX checksums. Сохранённые
`source_references` в каталоге — пути внутри исходного исследовательского набора;
эти декомпилированные файлы не поставляются с публичным репозиторием.
Каталог воспроизводит извлечённые метаданные, но сам по себе не позволяет повторно
декомпилировать APK. Серверный код Meta в исследовании отсутствует.

## Локальные проверки

```sh
python -m unittest discover -s tests -v
python examples/offline_demo.py
python tools/check_release.py
```

Проверки охватывают wire envelope, заголовки, canonical-поля, ownership,
сохранение null/0, ошибки GraphQL, HTTP-отказы, NDJSON, незавершённые ответы,
закрытие редиректов, API библиотеки, CLI, каталоги и отсутствие секретов в экспорте.

совместимость обработки, но не считается дополнительными сетевыми запросами.
